# Капибара

## ⚡ Сборка APK. Nitron

Это современный инструмент, который сам собирает APK, не требуя Android SDK - нужен только Node.js и Java.

**Требования:**
 1. **Node.js** (версия 18+)
 2. **Java JDK 17+**

**Шаги:**
1. Собрать APK командой:

   ```bash
   npx nitron build
   ```
3. Готовый файл появится в **`dist/app.apk`**
